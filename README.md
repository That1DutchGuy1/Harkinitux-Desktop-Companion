# Harkinitux Desktop Companion

<img src="Harkinitux.png" width="250px" alt="Harkinitux"/>

What if you fused King Harkinian together with Tux? Well, then you get this abomination named Harkinitux. To install him, just download the ```.deb``` package and install it via the Package Manager. Or in type in the terminal:
```
sudo dpkg -i harkinitux_1.0.deb
sudo apt-get install -f
harkinitux &
```

It's fucking simple. You can pick him up, drag him around your desktop, and place him back down wherever you want. Right-click on him for a funny Linux quote. That's literally it.
